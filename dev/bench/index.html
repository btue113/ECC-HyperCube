ecc-hypercube decode time

One point per commit to main. Each run builds the commit and a fixed baseline commit (179e6b2) on the same GitHub ubuntu-latest runner, decodes the same frames on one thread with each in alternating rounds, and takes the median ratio of the commit's time to the baseline's. That ratio is shown in µs per word by scaling it with the baseline's reference time on one fixed CPU.

Runner CPUs differ by up to 1.6× in absolute speed, but that cancels out of the ratio, so the µs per word and % views move together; about ±2% noise remains. Raw µs is what the runner measured. Slowdowns over 15% get a comment on the commit.
